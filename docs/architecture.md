## 001 ビルド環境: Vite + TypeScript（2026-11-08）

**決定**

- Vite 8.3.6、TypeScript 7.0.2 を使う。バージョンは `-E` で固定する
- 雛形は create-vite 9.3.4 の `vanilla-ts`（フレームワークなし）
- `tsconfig.json` に `"strict": true` を追加する

**理由**

- 画面数が少なく、標準の Web API で十分なため、フレームワークは入れない
- バージョンを固定すると、時間が経ってから `npm install` しても同じ環境を再現できる
- 音声処理は不具合の原因を追いにくいので、型チェックを厳しくして早めに間違いを見つける

**却下した案**

- React / Preact: 依存とバンドルサイズが増える。この規模なら Web 標準 API だけで足りる
- `^` 付きの範囲指定: 知らないうちにメジャー更新以外の変更が入り、同じ環境を再現できなくなる
