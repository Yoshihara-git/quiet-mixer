# Quiet Mixer デザイン決定

> ステータス: v0.1（2026-11-08）— 方向性確定（採用案 M「オーロラとすりガラス」）

---

## 1. 決定の経緯

| 段階 | 試した案 | 結果 |
| ---- | -------- | ---- |
| 1 | A 常夜灯 / B 真空管ラジオ / C 夜の水面 | A を保留 |
| 2 | D 星図 / E 月齢 / F 年輪（モチーフ案） | 不採用。「モチーフはいらない、普通の音源再生アプリとして」 |
| 3 | I 標準リスト / J 行を開いて詳細 / K タブバー型 / L 再生操作が主役 | 方向修正。グラデーションで洗練させる方針へ |
| 4 | M オーロラとすりガラス / N 色付きカード / O アートワーク主役 | **M を採用**。詳細の折りたたみを追加し、全画面を作成 |

---

## 2. コンセプト

- **ファイルごとに固有のグラデーションを持たせ、それをトラックの「色の名札」にする**
  - 名前を隠しても、色でどのトラックか見分けられる（F-05 と両立）
  - 再生位置・音量バーの塗りも、そのトラックの色にする
- 背景は夜色の地に、ぼかした光（オーロラ）を少しだけ置く。カードと操作パネルはすりガラス
- 就寝画面だけは例外で、純黒・極低輝度（要件 4.4）

---

## 3. カラートークン

### 3.1 ベース

| トークン | 値 | 用途 |
| -------- | -- | ---- |
| `--bg` | `#07060B` | 画面の地 |
| `--text` | `#F2E9DF` | 本文・数値 |
| `--text-sub` | `#B9AEA4` | 補足・ラベル（`--bg` 上で約 9:1） |
| `--text-strong` | `#F7EFE6` | つまみ・強調 |
| `--on-accent` | `#160B0A` | グラデーション塗りの上の文字・アイコン |
| `--danger` | `#F29AA6` | 削除・エラー（背景 `rgba(233,104,120,.16)`） |
| `--glass` | `rgba(255,255,255,.05)` | カード面 |
| `--glass-border` | `rgba(255,255,255,.09)` | カード枠 |
| `--glass-strong` | `rgba(20,14,18,.55)` | 下部操作パネル |
| `--track-bg` | `rgba(255,255,255,.12)` | スライダーの未塗り部分 |

### 3.2 アクセント（アプリ全体）

- `--accent-a: #F0A951`（琥珀）→ `--accent-b: #D9667A`（ローズ）
- 主ボタン（大）: `linear-gradient(120deg, #F0A951, #D9667A 60%, #9B5BB5)`

### 3.3 トラック色（8 組 = 上限 8 トラック）

| # | A | B | 印象 |
| - | - | - | ---- |
| 1 | `#F0A951` | `#D9667A` | 琥珀→ローズ |
| 2 | `#F5C26B` | `#E07B39` | 金→橙 |
| 3 | `#C77DBA` | `#7A5AC9` | 藤→菫 |
| 4 | `#E8907A` | `#B4567A` | 桃→ベリー |
| 5 | `#8FC98F` | `#4F9C8A` | 若葉→青緑 |
| 6 | `#8FB3D9` | `#5A6FC9` | 空→藍 |
| 7 | `#E58FB0` | `#8E4E8C` | 薔薇→葡萄 |
| 8 | `#D9C3A0` | `#8C7A66` | 砂→灰褐 |

- 色はファイル ID から決定的に割り当てる（同じファイルは常に同じ色）
- 方向は 135deg（スウォッチ）、90deg（バーの塗り）
- 一時停止中のトラックはスウォッチを `opacity: .5`、カードを `.72`
- 未決: 9 本目以降のファイル（ライブラリ側）は 8 色を巡回させる

### 3.4 オーロラ（背景の光）

- 画面ごとに 3〜4 個の楕円を `filter: blur(90–100px)`、`opacity: .18–.35` で配置
- 色はアクセントとトラック色から選ぶ（トラック詳細画面はそのトラックの色）
- 設定「背景の光」をオフにすると無地の `--bg` だけになる（電池対策）
- 静止表示。動かさない

## 4. タイポグラフィ

- 書体: **Manrope**（英数字・ファイル名）＋ **Noto Sans JP**（日本語）
  - `font-family: 'Manrope', 'Noto Sans JP', sans-serif`
  - オフライン動作のため、実装時はサブセット化して同梱する（要検討: 容量）
- 数値は必ず `font-variant-numeric: tabular-nums`
- サイズ（px）: 画面見出し 24/700、詳細の見出し 18/700、トラック名 15/600、本文 14、補足 13、ラベル・時間 12
- 全部大文字のラベルは使わない

## 5. 形・余白

| 対象 | 角丸 |
| ---- | ---- |
| スウォッチ | 12 |
| 入力欄・小ボタン | 14〜16 |
| リスト行 | 18 |
| トラックカード・セクション | 22 |
| 下部操作パネル | 26 |
| ピル・円ボタン | 高さの半分 |

- 画面の左右余白 16px、カード内余白 12〜16px、カード間 10px
- タップ領域は 44px 以上（主要ボタンは 48〜64px）
- すりガラス: `backdrop-filter: blur(24px)`（パネルは 28px）

## 6. コンポーネント

### 6.1 トラックカード（再生中画面）

| 状態 | 表示 |
| ---- | ---- |
| 折りたたみ | スウォッチ、名前、`経過 / 全体　音量 N`、開閉の矢印、再生/一時停止、細い進捗線（3px） |
| 展開 | 上記＋再生位置バー（時間表示つき）、音量バー（0〜150）、ループと速度のチップ、「範囲・速度を編集」 |

- 名前の行全体が開閉ボタン（`aria-expanded`）。再生ボタンは独立
- 「すべて折りたたむ / すべて開く」を一覧の右上に置く
- 既定: 先頭のみ展開（要検討: 前回の状態を記憶するか）
- 開閉アニメーションは `prefers-reduced-motion: no-preference` のときだけ

### 6.2 スライダー

- `<input type="range">` を使い、トラックは 4px、つまみは 14px の `--text-strong`
- 塗りは `linear-gradient(90deg, var(--a), var(--b)) 0 0 / var(--p) 100% no-repeat` で、`--p` を値に合わせて更新

### 6.3 その他

- スイッチ: 44×26。オンはグラデーション、オフは枠線のみ
- セグメント: 地 `rgba(255,255,255,.06)`、選択中はグラデーション
- 名前を隠すボタン: オフは枠線のピル、オンはアクセントのグラデーション塗り
- 状態バッジ: 再生中（琥珀）、読込中（進捗つき）、再生できません（`--danger`）

## 7. 画面

| 画面 | 主な要素 |
| ---- | -------- |
| 再生中 | 名前を隠す・ミックス・ライブラリ（上）、トラックカード、操作パネル（停止、タイマー、全体の再生/一時停止、おやすみ、全体音量） |
| ライブラリ | 検索、リスト/グリッド切替、絞り込み（種類・タグ）、並び替え、ファイル行（種別・波形・長さ・サイズ・状態）、保存領域、ファイルを追加 |
| トラック詳細 | 波形上の範囲指定と数値入力、範囲ループ、速度（0.5〜1.5）、左右の位置、フェードイン、別名・タグ、再生中から外す |
| ミックス | 今の組み合わせを保存、保存済み一覧と再生、書き出し・読み込み |
| おやすみ | 純黒に時計・残り時間・解除案内のみ |
| 設定 | 表示 / 再生 / おやすみ画面 / 保存領域、輝度の案内 |

### 7.1 おやすみ画面（例外ルール）

- 背景 `#000`、文字は要件どおり `#1a1a1a` 程度（モックは確認用に `#2A2326`）
- オーロラ・すりガラス・グラデーションの塗りは使わない（残り時間の線のみ 16% の不透明度）
- コントラスト AA の意図的な例外（要件 4.4 / 5 章）
